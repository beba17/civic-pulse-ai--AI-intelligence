# Civics Plus — Hackathon Presentation Notes\n\n## Problem\nCitizen reports can remain fragmented. Civic teams need a clearer way to see recurring issues, supporting evidence, and local context.\n\n## Solution\nCivics Plus is a civic-intelligence prototype that turns citizen inputs into structured signals, hotspot views, evidence summaries, recommendations, and AI-assisted civic guidance.\n\n## Product demo\nThe current React application demonstrates civic signal/hotspot dashboards, citizen issue intake, evidence filtering, recommendation review states, and the Ask Civics Plus assistant.\n\n## AI layer\nThe app uses `@google/genai` with Gemini 2.5 Flash when `VITE_GEMINI_API_KEY` is configured. If Gemini is unavailable, a deterministic local civic-knowledge fallback keeps the demo usable.\n\n## Architecture\n~~~text\nCitizen / reviewer -> React + Vite -> Civic dashboard / evidence\n                                  -> Ask Civics Plus -> Gemini 2.5 Flash -> civic guidance\n~~~\n\n## Responsible AI\nThe prototype treats AI as decision support. Dashboard records are seeded/demo data, and consequential civic actions require human review. Important scheme or department information should be verified against official sources.\n\n## Hackathon positioning\nThe UI is positioned for the Code for Communities Hackathon, Cooperation Track, with a Digital Public Good prototype focus.\n\n## Links\n- Live demo: https://civics-plus.ai.studio/\n- Repository: https://github.com/beba17/civic-pulse-ai--AI-intelligence\n
